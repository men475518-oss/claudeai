# AFTERGROVE（アフターグローヴ）

> **AfterPlace** のような、**縦持ち・片手で遊べる探索アクション RPG**。
> ブラウザだけで動きます。インストールもビルドも不要。

荒れはてた谷にひとり降り立ち、まもの に囚われた村人を助け、
村を建てなおしながら 3 つの遺物を集める――そんな小さな冒険です。

```
   ドラッグ = 移動 ／ タップ = 斬る ／ 長押し = ためて回転斬り
```

---

## 遊びかた

### 起動

**いちばん手軽な方法**：`dist/aftergrove.html` をダブルクリック。
全部入りの 1 ファイルなので、サーバも通信もなしでそのまま遊べます。

**開発するとき**は `src/` を直接読む `index.html` のほうを使います。
ES モジュールなので簡単なサーバが必要です。

```bash
python3 -m http.server 8765
# → http://localhost:8765/ をスマホ／ブラウザで開く
```

1 ファイル版を作りなおすには（依存パッケージなし）:

```bash
node tools/build.mjs          # → dist/aftergrove.html
```

スマホでは「ホーム画面に追加」すると全画面のアプリとして遊べます。
横画面やパソコンの大きな画面では、縦長のゲーム画面が中央に置かれます。

### 操作

| したいこと | スマホ（片手） | キーボード |
|---|---|---|
| 移動 | 画面下側をドラッグ（どこからでもスティックが出る） | `WASD` / 方向キー |
| 斬る | **画面のどこでも その場でタップ**（右下の赤ボタンでも可） | `Space` / `J` / `Z` |
| ためる（回転斬り） | その場で長押し → 離す | `Space` 長押し |
| **ころがる（回避）** | **すばやく指を払う** | `Shift` / `C` |
| 道具（爆弾・薬・魔法） | 右下の青ボタン | `K` / `X` |
| 道具のきりかえ | 青ボタンの上の小さいボタン | メニューから |
| 調べる・話す | 対象に近づいて タップ／赤ボタン | `Space` |
| マップ | 右上のマップアイコン | `M` |
| メニュー | 右上の三本線 | `Esc` / `P` |

画面のどこでも、ドラッグすれば歩き、その場でタップすれば斬ります。
近くに立て札や宝箱など**調べられるものがあるときだけ**、タップはそちらに使われます。
ボタンが邪魔なときは **メニュー → 「ボタンをかくす」** で消せます。

## 世界のかたち

大きな一枚地図ではなく、**小さな島がいくつも小道でつながった「部屋づたい」の世界**です。
島はどれも暗がりに浮かぶ草地で、まわりを生け垣がふちどっています。
端の小道へ歩くと、となりの島へ移ります。全部で 34 島。

マップ画面は、その島のつながりを**点と線のグラフ**で描きます。行った島は名前つき、
まだの島は「？」。ほら穴・村人・町・門には印がつきます。

## ゲームの流れ

1. **家のまわりで目をさます。** 手持ちは なまくらな刃だけ。
2. **島づたいに探索。** 島ごとに景色と敵が違い、宝箱、立て札、そして **檻に囚われた村人**。
3. **檻を斬って村人を助ける。** 助けた村人ごとに、村で建てられる建物が解放される。
4. **コインを貯めて村を再建。** よろず屋・かじ屋・いやしの家・賢者の塔・畑・井戸。
   剣を鍛え、ハートの器を増やし、魔法を覚える。
5. **3 つのほら穴に潜る。** カギを見つけ、扉を開け、いちばん奥の門をくぐる。
   ひび割れた壁は爆弾で開く。その先には隠し部屋がある。
6. **門の向こうは「主」の舞台。** 紫の空、降りつづける短剣、地平線に立ちならぶ影。
   地平線からのぞきこむ巨大な顔が、長い腕を伸ばして地面に手を叩きつけてくる。
   **降りてきた手だけが斬れる**。短剣の雨、腕のなぎ払い、そして画面いっぱいの
   かぶりつき——ころがって、よけて、殴る。倒すと **遺物** が残る。
7. **遺物 3 つで「古い門」が開く。** ――朝が来る。

道ばたの **祠** に触れると、いちばん近い用事の方角を教えてくれます。
**自販機** は 15 コインで何か出ます（出ないこともあります）。
**帽子の人** はどこかに立っていて、進み具合に応じて違うことを言います。

いまの目標はマップ画面とメニューに出ます。ほら穴と門は、まだ行っていなくても
マップにうっすら印がつくので、迷ったらマップを開いてください。

セーブは自動（`localStorage`）。家で「ねむる」と全回復＋セーブもできます。
力尽きても、コインを少し落として村のベッドで目をさますだけです。

## 技術メモ

- **依存ゼロ。** 素の ES モジュール＋Canvas 2D のみ。ビルド工程なし。
- **ボスは背景と実体の合わせ技。** 頭・胴・腕は背景レイヤーに手続き描画し、
  地面に降りた「手」だけを当たり判定を持つ実体として並べる。
  かぶりつきは同じ頭を 7.5 倍に拡大して画面へ寄せているだけ——低解像度
  キャンバスに描いているので、拡大すると自然にドット絵になる。
- **画像・音声ファイルもゼロ。**
  - ドット絵は文字列（`src/artdata.js`）から `ImageData` を組み立てて生成。
  - 地形タイルは値ノイズで手続き生成し、隣り合うバイオームはディザで馴染ませる。
  - 効果音と BGM は WebAudio のオシレータで合成（バイオーム／ダンジョン／ボスで曲が変わる）。
- **二段構えの解像度。** ゲーム画面は 176px 幅の低解像度キャンバスに描いてから
  ニアレストネイバーで拡大し、UI と日本語テキストは実解像度のまま描画。
  ドット絵の質感と、文字の読みやすさを両立させています。
- **世界は決定論的な島のグラフ。** シード値からグリッド上に 34 島を生やし、
  ループを何本か足してから、家からの距離で島の種類と名前を決めます。
  ほら穴・村人・門は、その距離をもとに配ります。
  島そのものは「丸みのあるひし形＋ノイズ」の形に切り出し、
  出口の首だけを外へ掘るので、輪郭がきれいなまま小道がつながります。
  16 個のシードで自動検証したところ、どれも全島がひとつながりで、
  ほら穴 3 つ・村人 7 人・町・門にすべて歩いて行けました（生成は最大 10ms）。
- **縦画面前提のカメラ**と、画面下のどこからでも出る**フローティングスティック**で
  片手操作に寄せています。

### ファイル構成

```
index.html          画面の器（キャンバスと起動）
src/
  main.js           進行・状態遷移・当たり判定の解決
  config.js         定数
  util.js           数学・乱数・ノイズ
  artdata.js        ドット絵データ（文字列）
  art.js            スプライト／地形タイルの生成
  render.js         カメラ・タイル描画・奥行きソート・明かり
  input.js          タッチ（片手ジェスチャ）とキーボード
  audio.js          WebAudio による効果音と BGM
  world.js          タイル地図・地形定義・オーバーワールド生成
  dungeon.js        ダンジョン生成
  entities.js       プレイヤー・敵・NPC・落ちもの・弾
  fx.js             パーティクル・画面ゆれ・ヒットストップ
  ui.js             HUD・会話・メニュー・マップ・タイトル
  rooms.js          島のグラフ生成と、島ひとつぶんの地面づくり
  island.js         島の輪郭・小道・生け垣・池を なめらかな一枚絵として描く
  story.js          この世界のことば（会話・立て札・エンディング）
  arena.js          ボス戦の舞台（空・地平線の影・降る短剣）
  boss.js           巨大ボスと、地面に降りてくる手
  hazard.js         予告つきの危険（短剣の雨・腕のなぎ払い）
  bubble.js         頭上の吹き出し
  save.js           localStorage への保存
tools/
  build.mjs         src/ を 1 枚の HTML にまとめる自作バンドラ
dist/
  aftergrove.html   その出力（そのまま配布・オフライン起動できる）
```

### 動作確認

ブラウザを実際に動かして、遊びの筋道をひととおり検査するテストがあります。

```bash
npm i -D playwright          # ブラウザ本体は既存のものを使う
node tests/play.test.mjs     # src/ 版
node tests/play.test.mjs --single   # dist/aftergrove.html 版
```

検査するのは 28 項目 ―― 16 シードぶんの生成（全島がひとつながりか、
ほら穴・村人・町・門へ行けるか、島の名前が重複しないか）、
**画面のどこをタップしても剣を振るか**、**小道を通ってとなりの島へ渡り戻れるか**、
**島のまわりが暗がりになっているか**、
ドラッグ移動、剣とためうち、払いでのころがり、祠と自販機と帽子の人、
立て札の吹き出し、爆弾、村人の救出と建築、ダンジョン、
ボスの舞台で手が降りてきて殴れて倒せるか、遺物、
**セーブとロード（いた島まで戻るか）**、エンディング、力尽きたときの復帰、
6 種類の画面サイズで操作ボタンが画面内に収まっているか。
実行中に例外が出ないことも確かめます。

## クレジット

AfterPlace（Evan Kice 氏の作品）に着想を得た**オマージュ作品**です。
コード・アート・音はすべてこのリポジトリ内で新規に作ったもので、
元作品のアセットやコードは一切含みません。
